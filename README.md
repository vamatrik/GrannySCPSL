# Русское описание

## Для кого сделан этот плагин?
Этот плагин сделан для всех желающих пострадать) Если вы ютубер, можете спокойно снимать ролики с ним, вам будет интересный челлендж.
Если вы стример, можете спокойной постримить с ним, там нету запреток.

## Как установить плагин?

Зайдите в папку Release и скачайте .dll файл.
Зайдите в директорию вашего SCP: SL.
В папку LabAPI, plugins, global положите данный плагин.
После этого запустите либо Dedicated Server, либо пропишите команду host в консоль игры
(плагин проверялся на выделенном сервере, так что не уверен, что все будет работать с командой host)

## Описание плагина

### Начало

Вы появитесь в комнате ожидания. Для начала игры зайдите в настройки, server specific settings и нажмите кнопку играть.
Важно! Для начала у вас должны быть админские права на сервере.
(на host пишите adminme, а на выделенном сервере впишите ваш steamid в файл
"C:\Program Files (x86)\Steam\steamapps\common\SCP Secret Laboratory Dedicated Server\ConfigTemplates\config_remoteadmin.template.txt"
Там будет графа ....@steam: owner. Впишите туда ваш стим айди)
После начала игры цель будет одна - сбежать из легкой зоны.

### Игровой процесс

На карте спавнятся предметы, лимит слотов инвентаря - 1.
Надо быть осторожными! Вскоре после вашего пробуждения проснется и гренни. Она слышит прыжки, бег и выброс предметов из инвентаря.
Каждый раз, когда гренни слышит вас по этим трем причинам, вам отправляется звуковой индикатор об этом. Прячьтесь!
Чтобы гренни хуже вас видела, встаньте на месте на пять секунд. Тогда ей будет очень тяжело вас заметить.

# English Description

## Who is this plugin for?

This plugin is made for anyone who wants to suffer a bit 😊 If you're a YouTuber, feel free to record videos with it – it'll be an interesting challenge.
If you're a streamer, you can safely stream with it – there are no restrictions.

## How to install the plugin?

Go to the Release folder and download the .dll file.
Navigate to your SCP: SL directory.
Place this plugin into the LabAPI, plugins, global folder.
After that, either launch the Dedicated Server or type the host command in the game console
(the plugin was tested on a dedicated server, so I'm not sure everything will work with the host command).

## Plugin description

### Start

You will appear in the waiting room. To start the game, go to Settings, Server Specific Settings, and click the Play button.
Important! You must have admin rights on the server first.
(for host type adminme; for a dedicated server, add your SteamID to the file
C:\Program Files (x86)\Steam\steamapps\common\SCP Secret Laboratory Dedicated Server\ConfigTemplates\config_remoteadmin.template.txt
There you'll find a line like ....@steam: owner. Enter your Steam ID there.)
Once the game starts, your goal will be one: escape from the Light Containment Zone.

### Gameplay

Items spawn on the map, and the inventory slot limit is 1.
Be careful! Shortly after you wake up, Granny will wake up too. She hears jumping, running, and dropping items from the inventory.
Every time Granny hears you for any of these three reasons, a sound indicator will be sent to you. Hide!
To make it harder for Granny to see you, stand still for five seconds. Then it will be very difficult for her to spot you.
