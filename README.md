# Русское описание
## Для кого сделан этот плагин?
Этот плагин сделан для всех желающих пострадать) Если вы ютубер, можете спокойно снимать ролики с ним, вам будет интересный челлендж.
Если вы стример, можете спокойной постримить с ним, там нету запреток.
## Как установить плагин?
Зайдите в папку Release и скачайте .dll файл.
Зайдите в директорию вашего SCP: SL.
В папку LabAPI, plugins, global положите данный плагин.
После этого запустите либо Dedicated Server, либо пропишите команду host в консоль игры
(плагин проверялся на выделенном сервере, так что не уверен, что все будет работать с командой host)
## Описание плагина

Вы появитесь в комнате ожидания. Для начала игры зайдите в настройки, server specific settings и нажмите кнопку играть.
Важно! Для начала у вас должны быть админские права на сервере.
(на host пишите adminme, а на выделенном сервере впишите ваш steamid в файл "C:\Program Files (x86)\Steam\steamapps\common\SCP Secret Laboratory Dedicated Server\ConfigTemplates\config_remoteadmin.template.txt"
Там будет графа ....@steam: owner. Впишите туда ваш стим айди)
После начала игры цель будет одна - сбежать из легкой зоны.
На карте спавнятся предметы, лимит слотов инвентаря - 1.
Надо быть осторожными! Вскоре после вашего пробуждения проснется и гренни. Она слышит прыжки, бег и выброс предметов из инвентаря.
Каждый раз, когда гренни слышит вас по этим трем причинам, вам отправляется звуковой индикатор об этом. Прячьтесь!
Чтобы гренни хуже вас видела, встаньте на месте на пять секунд. Тогда ей будет очень тяжело вас заметить.
